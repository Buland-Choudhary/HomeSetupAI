# Hackathon project — AI Tinkerers NYC "Agents, Everywhere"

Project decisions: @PROJECT.md · Build plan & milestones: @plan.md · API details: @TECH_NOTES.md

This folder is a hackathon build for the **AI Tinkerers "Agents, Everywhere" global hackathon (with OpenAI)**, Sat **2026-09-12**, NYC (venue: Veris AI). Full event details: @HACKATHON.md

## Decision rules for every choice in this project
- **The agent must live inside an existing environment** (Slack, Teams, email, browser, messaging, mobile, voice, wearables, robotics…) and that context must be *essential* — a generic chatbot/wrapper scores 1 on Innovation.
- **Working end-to-end demo > breadth.** Judges score 1–5 on: Core Functionality · Innovation & Theme Alignment · Technical Execution & Integration · Usefulness & Agentic Experience.
- **Hard time box:** build ends **3:30 PM EDT**; submissions planned for **3:30–4:00 PM EDT**; portal's hard submission cutoff is **4:30 PM EDT**. Scope ruthlessly; cut features before cutting reliability.
- **Net-new code only** — templates/libraries/starter code are fine, but core functionality must be built today. Be ready to explain what was built during the event.
- **Submission deliverables:** title · written description (what, for whom, why the context matters) · **public GitHub repo** · **2-minute demo video** · social post tagging sponsors. Keep the README demo-ready.
- Prefer sponsor tools where they genuinely help — side prizes exist for **Ambiguous AI** and **CopilotKit**.
- Handle failures gracefully in the demo path (judges reward "thoughtful failure handling").
